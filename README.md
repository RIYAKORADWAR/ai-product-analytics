# AI Product Analytics Platform

A scalable product analytics platform designed to track user behavior events,
store them efficiently, and compute key business metrics such as DAU, funnels,
and retention.

## 🚀 Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Python

## 📊 Features
- Event tracking API
- Structured event schema
- Scalable backend architecture
- Ready for analytics and dashboards
